# محمد حسن الموسوي — معرض أعمال

موقع داكن محوره **مروحة فيديوهات**: الفيديو الأوسط يعمل تلقائياً وصامتاً فور فتح الصفحة، والباقي يعرض كادراً ثابتاً. ثنائي اللغة عربي–إنجليزي مع قلب كامل للاتجاه.

---

## التشغيل

```bash
cd "c:\Users\mohmed\Desktop\بروتوفوليو محمد ابو القاسم"
python serve.py
```
ثم افتح **http://localhost:5173**
(المنفذ ٥١٧٣ مشغول عندك بمشروع آخر؟ استخدم `python serve.py 5199`)

### لماذا `serve.py` ولا نستخدم `python -m http.server`؟

| | `http.server` | `serve.py` |
|---|---|---|
| طلبات Range | ❌ | ✅ |
| القفز داخل الفيديو | ❌ | ✅ |
| تحميل جزء من الملف | ❌ يحمّل ٣٣٣ م.ب كاملة | ✅ يحمّل المطلوب فقط |
| الخطوط المحلية | ❌ يحجبها كروم من `file://` | ✅ |

بدون دعم Range المتصفح لا يستطيع القفز في الفيديو، وقد يرفض التشغيل أصلاً.

**لا تفتح `index.html` بالنقر المزدوج** — الخطوط والفيديو لن يعملا.

## تحرير الأعمال

كل شيء في `js/data.js`. **العناوين الحالية مبدئية** («عمل ٠١»…) — استبدلها بأسماء أعمالك:

```js
{
  id: 'v01', file: 'v01.mp4', ar: 0.5625, dur: 37, mb: 4.3,
  cat: 'vert', heavy: false,
  title: { en: 'Brand Film — Kayan', ar: 'فيلم علامة — كيان' },
  note:  { en: 'One sentence.',      ar: 'جملة واحدة.' }
}
```

| الحقل | المعنى |
|---|---|
| `ar` | نسبة العرض ÷ الارتفاع. `0.5625` = عمودي 9:16 · `1.7778` = أفقي 16:9 |
| `dur` | المدة بالثواني — تظهر على البطاقة بصيغة `د:ث` |
| `mb` | الحجم — يظهر في المشغّل |
| `heavy` | `true` يمنع التحميل التلقائي تماماً |
| `cat` | `vert` أو `wide` — للفلاتر |

### كيف تُوزَّع الأعمال

الموقع يفصل الصيغتين بدل خلطهما — لأن خلطهما في مروحة واحدة كان يجعل البطاقة الأفقية أعرض بثلاث مرات من العمودية فتبتلع جيرانها:

| القسم | ماذا يعرض | الشكل |
|---|---|---|
| المروحة في الصدر | الأعمال العمودية (`ar < 1`) | كلها ٩:١٦ بمقاس واحد |
| قسم «أعمال عريضة» | الأعمال الأفقية (`ar > 1`) | كلها ١٦:٩ في صف |

التوزيع **تلقائي** من قيمة `ar` — أضف عملاً عمودياً فيدخل المروحة، وأفقياً فيدخل الصف العريض. لا شيء لتضبطه يدوياً.

**لا قصّ ولا فراغ:** كل عمل يظهر بنسبته الحقيقية كاملة.

**لإضافة فيديو:** ضعه في `assets/video/` وأضف كائناً جديداً. لا شيء آخر.

هذا أهم ما في الموقع مع ملفات بهذا الحجم:

| العنصر | ما يُحمَّل |
|---|---|
| البطاقة المركزية | الفيديو كاملاً ويعمل تلقائياً (صامت، مكرّر) |
| الجارتان (±1, ±2) | الميتاداتا فقط + كادر عند الثانية ~1 |
| البقية | لا شيء |
| الملفات الثقيلة | لا شيء أبداً حتى الضغط على تشغيل |

### ضبط المروحة

في كتلة `:root` بـ `css/style.css`:

```css
--ch:  clamp(258px, 38vw, 500px);  /* ارتفاع البطاقة — العرض يُحسب منه */
--x1:  .78;    --x2: 1.48;         /* التباعد */
--r1:  6.5deg; --r2: 13deg;        /* الميلان */
--s1:  .93;    --s2: .84;          /* التصغير */
```

المقاسات الناتجة:

| عرض الشاشة | البطاقة الوسطى |
|---|---|
| ١٤٤٠ | ٢٨١ × ٥٠٠ |
| ١٠٢٤ | ٢١٩ × ٣٨٩ |
| ٧٦٨ | ١٦٤ × ٢٩٢ |
| ٣٩٠ (جوال) | ١٤٥ × ٢٥٨ |

عرض المروحة كاملة على ١٤٤٠ = ١٠٦٩ بكسل داخل حاوية ١١٨٠ — بلا قصّ. وعلى الشاشات دون ٧٦٠ تختفي البطاقتان الخارجيتان فتبقى ثلاث بطاقات تتّسع للشاشة.

## أنيميشن السكرول

### التخميد — سرّ الإحساس بالسلاسة

الحركة لا تلتصق بالسكرول ١:١. لكل قيمة **هدف** يتبع السكرول فوراً و**قيمة حالية** تلحق به بتخميد كل إطار:

```js
C[k] += (T[k] - C[k]) * EASE_K;      // EASE_K = 0.085
```

هذا ما يعطي الثقل والانسياب بدل الحدّة. **لتغيير الإحساس عدّل `EASE_K` وحده** في `js/main.js`:

| القيمة | الإحساس |
|---|---|
| `0.04` | بطيء وثقيل جداً |
| `0.085` | الحالي — منساب |
| `0.18` | سريع ومشدود |
| `1.0` | ملتصق بالسكرول تماماً (كما كان) |

الحلقة تعمل فقط ما دامت القيم لم تستقرّ ثم تتوقّف — لا `requestAnimationFrame` دائم يستهلك البطارية.

### المدى والمدد

وسّعت مدى انفتاح المروحة من `0.72` إلى `1.05` من ارتفاع الشاشة، فصار أطول نفَساً. والمدد: البطاقات `980ms`، الكشف `1000ms`، و`--dur` من `260ms` إلى `340ms`.

| الحركة | المصدر |
|---|---|
| نص الصدر يرتفع ويخفت | موضع الصفحة |
| **انفتاح المروحة** | موضع قسم `#showcase` |
| ميلان المروحة | موضع قسم `#showcase` |

| الشريط المتحرّك | موضع الصفحة |

## الكشف السينمائي عند السكرول

الإحساس المطلوب مصدره **الـ blur**: العنصر يصل خارج التركيز ثم يحدّ — لا مجرّد إزاحة. أربع صيغ حسب نوع العنصر، تُطبَّق بسمة `data-rv`:

| الصيغة | الحالة الأولى | لأي عنصر |
|---|---|---|
| `text` | إزاحة ٢٨px + `blur(10px)` | العناوين والفقرات والمهارات والشهادات |
| `card` | إزاحة ٢٨px + `scale(.95)` | بطاقات الخبرات والعملاء |
| `scale` | `scale(.9)` | بطاقات الأرقام |
| `img` | `scale(1.1)` + إزاحة + `brightness(.5) blur(10px)` | بطاقات الفيديو في الصف |

المدة `1200ms` والمنحنى `cubic-bezier(.25, 1, .3, 1)`، ويبدأ الكشف حين يبلغ العنصر ٨٠px قبل حافة الشاشة. المتجاورون يتدرّجون بفارق ٩٠ms بحدّ أقصى ست خطوات.

**ما كان ظاهراً على الشاشة عند أول رسم يُثبَّت فوراً بلا حركة** (`rv-now`) — فلا يرى الزائر صفحة فارغة تتجمّع أمامه.

`will-change` يُرفع عن العنصر بعد اكتمال كشفه فلا تتراكم طبقات في الذاكرة.

**المروحة مستثناة** — لها حركة الانفتاح الخاصة، والمحرّك يكتب `transform` عليها كل إطار فأي كشف سيُلغى فوراً.

## الهيدر

### الديسكتوب — جزيرة عائمة

الهيدر لم يعد شريطاً ملتصقاً بأعلى الصفحة. صار **جزيرة** بحواف دائرية وهامش من الأطراف وخلفية ضبابية صلبة، فينفصل بصرياً عن البطاقات بدل أن تمرّ تحته. وزدت الفسحة بينه وبين المروحة.

الاسم والتخصص صارا في سطر واحد تفصلهما نقطة ذهبية — بدل سطرين يرفعان ارتفاع الشريط.

### الجوال — لوح بملء الشاشة

بدل حشر الاسم والروابط وزرّين في صندوق ضيّق، صار الشريط سطراً واحداً: **الاسم + زر قائمة**. والضغط عليه يفتح لوحاً بملء الشاشة فيه:

- الروابط بخط كبير (‏٢.٩rem) تظهر واحداً بعد الآخر بتأخير متدرّج
- توهّج خفيف بلون العمل الحالي في الخلفية
- زر اللغة وزر التواصل بالأسفل خلف خط فاصل
- يُغلق بالضغط على أي رابط أو بـ `Esc`، مع حصر التركيز داخله

**لا تكرار في الشيفرة:** نفس الروابط تُستخدم في الحالتين. على الديسكتوب اللوح `display: contents` فيندمج أبناؤه في شبكة الهيدر، وعلى الجوال يتحوّل إلى `position: fixed`.

> **مطبّ تقني عولج:** `backdrop-filter` على شريط الهيدر يجعله حاوية لأي ابن `position: fixed`، فكان اللوح سينحصر داخل الشريط بدل ملء الشاشة. لهذا يُلغى الضباب في مقاس الجوال وتُستخدم خلفية صلبة.

### الصدر بلا فيديو

المروحة لم تعد في الصدر. الزائر عند دخوله يرى **الاسم فقط** على شاشة كاملة، ثم تنكشف المروحة مع النزول.

هذا غيّر سياسة التحميل جذرياً:

| | قبل | بعد |
|---|---|---|
| فيديو يُحمَّل عند الدخول | ٤.٣ م.ب | **صفر** |
| مجموع أول تحميل | ~٤.٥ م.ب | **~٢٢٢ ك.ب** |

لا بايت واحد من الفيديو يُطلب حتى يقترب قسم المروحة من الشاشة بـ ٣٠٠ بكسل (`rootMargin` في `IntersectionObserver`). وحُذف `<link rel="preload" as="video">` لأنه صار يزاحم الخطوط والـ CSS على أولوية غير مبرَّرة.

### انفتاح المروحة

`--fan` لم يعد مربوطاً بأعلى الصفحة بل **بموضع قسم `#showcase` نفسه**: البطاقات مكدّسة عند اقتراب القسم، وتنفتح تماماً حين يستقرّ في الشاشة. فالحركة تحدث حيث ينظر الزائر لا قبل وصوله.

## إمكانية الوصول

- البطاقة المركزية فقط في مسار الكيبورد، والأسهم تنقّل بين الأعمال
- المشغّل: `role="dialog"` + `aria-modal` + حصر تركيز + `Esc` + أسهم (تنعكس في RTL)
- كل فيديوهات العرض صامتة (`muted`) — لا صوت يفاجئ الزائر. الصوت في المشغّل وحده
- `prefers-reduced-motion` يوقف كل الحركة ومعاينات المرور
